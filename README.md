# 데이터 런

민트색 로봇 친구와 학교를 달리며 배우는 데이터 학습 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열고 이미지의 **게임 시작** 버튼을 누르면 바로 시작합니다. 설치나 로그인은 필요하지 않습니다. 그림과 문제 파일이 들어 있는 폴더 전체를 함께 보관하세요.

## 게임 방법

1. 로봇은 자동으로 달립니다. 문제를 읽고 알맞은 답을 고릅니다.
2. 마우스, 터치 또는 숫자 키 1·2·3으로 답합니다. 분류 문제는 1·2를 사용합니다.
3. 정답은 코인 10개, 3연속 정답마다 5개를 추가로 얻습니다.
4. 해설을 읽고 다음 문제로 이동합니다. 시간제한과 탈락은 없습니다.
5. 마지막에는 결과와 오답 해설을 확인하고 틀린 문제만 다시 풀 수 있습니다.

게임 중 Esc 또는 일시정지 버튼으로 잠시 쉬고, 탭을 벗어나면 자동으로 멈춥니다. 소리는 기본적으로 꺼져 있으며 버튼으로 켤 수 있습니다. 운영체제의 동작 줄이기 설정을 존중합니다.

## 코스

- 학교 한 바퀴: 38문제 전체. 급식실·화장실·교실·도서관·학교 정원을 탐험한 뒤 데이터 개념을 정리합니다.
- 짧게 달리기: 생활 속 데이터 4문제, 개념 3문제, 분류 3문제를 무작위로 골라 총 10문제를 풉니다.
- 데이터 분류: 수치형·범주형 10문제를 모두 풉니다.

문제는 제공된 JSON 38문제를 그대로 사용했습니다. 각 문항의 내용·정답·해설을 제공된 Word 정답해설 문서와 대조했습니다. `questions.json` 수정 시 `questions.js`도 같은 데이터로 갱신해야 합니다.

## GitHub Pages

별도 서버·API 키·빌드가 없는 정적 웹앱입니다. 모든 경로가 상대 경로이므로 GitHub Pages의 저장소 하위 경로에서도 실행됩니다.

공개 저장소에 이 폴더의 파일을 커밋하고 푸시한 다음, GitHub 저장소의 **Settings → Pages → Deploy from a branch → main / (root)**를 선택합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 게시 완료 여부는 Pages 설정의 실제 사이트 주소에서 확인합니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 검증

Node.js가 설치되어 있으면 `npm test`로 38문제 전체 완료, 점수, 중복 입력 방지, 오답 복습, 코스 구성, 파일 경로를 검증할 수 있습니다. 실행 자체에는 Node.js가 필요하지 않습니다.

## 이미지

시작 화면은 사용자가 제공한 이미지를 사용했습니다. 달리기 스프라이트와 학교 배경은 해당 이미지와 캐릭터를 참고해 내장 이미지 생성 도구로 제작했습니다. 사용한 제작 프롬프트는 `ASSET-PROMPTS.md`에 기록했습니다.

게임은 개인정보를 수집하거나 성적을 서버에 저장하지 않습니다. 새로고침하면 진행 중인 모험은 초기화됩니다.
