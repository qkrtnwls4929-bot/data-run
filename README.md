# 데이터 런

학교를 달리며 장애물을 피하고 데이터 문제를 푸는 교육용 러닝 웹게임입니다.

## 게임 흐름

1. 캐릭터가 자동으로 달립니다.
2. 화면, 점프 버튼, `Space`, `↑` 키로 점프합니다. 공중에서 한 번 더 눌러 2단 점프할 수 있습니다.
3. 데이터 코인을 모으고 낮은 장애물, 2단 높이 장애물, 낭떠러지를 피합니다.
4. 약 20~30초마다 보너스 문제가 나옵니다. 정답은 코인 20~50개를 무작위로 추가하고 오답은 코인 20개를 차감합니다.
5. 낭떠러지에 빠지면 달리기가 끝납니다. 장애물로 체력이 0이 되면 균형을 잃고 낙사합니다.
6. 달리기 보상인 데이터 조각으로 점프, 체력, 코인 센서를 강화하고 다시 달립니다.

점수는 `데이터 코인 × 10 + 달린 거리`이며 콤보 보너스와 게임 중 파워업은 없습니다.

## 러닝 규칙

- 점프 입력 유예인 코요테 타임은 0.09초입니다.
- 상승할 때보다 하강할 때 더 강한 중력을 적용합니다.
- 속도는 1분마다 5단계까지 높아지고 반응 가능한 최고 속도에서 제한됩니다.
- 급식실, 화장실, 교실, 도서관, 생활환경을 1분 단위로 순환합니다.
- 각 장소는 장애물 외형만 달라지고 충돌 규칙은 같습니다.
- 피격 시 화면 흔들림, 캐릭터 깜빡임, 효과음을 제공합니다.
- 코인 효과음은 획득할 때마다 음높이가 달라집니다.
- 빠른 속도에서는 바람 효과와 배경 시차가 강해집니다.

## 학습 목표

생활 속 데이터가 필요한 문제 상황을 보고, 문제 해결에 필요한 데이터를 찾습니다. 제공된 38개 문항과 해설을 보너스 문제로 사용합니다.

## 실행과 배포

`index.html`을 열면 설치 없이 실행됩니다. GitHub Pages에서는 `main` 브랜치의 루트 폴더를 게시합니다. 모든 자산은 상대 경로로 연결된 정적 파일입니다.

## 검증

`npm test`로 문제 데이터, 코스 구성, 점수 공식, 체력, 코인 보상과 상대 경로를 검증합니다.

시작 화면은 사용자가 제공한 이미지를 사용했습니다. 달리기 스프라이트와 학교 배경은 제공 이미지를 참고해 제작했습니다. 게임은 개인정보를 수집하지 않으며 강화 정보만 브라우저의 로컬 저장소에 보관합니다.
